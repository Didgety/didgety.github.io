Projects

  • 2026.10 - 2026.10
    Temporal calibration for a Steane memory
    Wrote the Qiskit implementation for Team Bells Pair at Qompute 2026. Simulated repeated correction in a seven-qubit Steane memory, implemented independent calibration circuits, and compared four decoders on held-out records.
  • 2026.01 - 2026.11
    Spectator-qubit dynamics on IBM Fez
    Extended a USC course project into a three-job IBM Fez experiment. Reconstructed a central qubit's state and measured a trace-distance revival under coherent exchange and a decrease in the spectator-reset control.
  • 2025.11
    Qiskit circuit library and transpiler
    Proposed a Rust qDRIFT implementation for the C API and collaborated on its follow-up. Submitted separate changes for delay padding, classical type logic, and Windows library discovery.
